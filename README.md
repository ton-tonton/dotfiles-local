## CLI tools

Install with Homebrew:

```sh
brew install bat eza fd ripgrep fzf zoxide jq tree git-delta starship
```

| Tool | What it does |
|---|---|
| `bat` | `cat` with syntax colors |
| `eza` | Better `ls` |
| `fd` | Faster `find` |
| `rg` (ripgrep) | Fast text search |
| `fzf` | Fuzzy finder |
| `zoxide` | Smart `cd` |
| `jq` | Read and change JSON |
| `tree` | Show folders as a tree |
| `git-delta` | Nicer git diffs |
| `starship` | Shell prompt |
